# Prompt 模板 ③ · 知识库即问即答（RAG 思路）

> 知识库要连 VPN、搜起来慢。两种用法：
>
> **用法 A（推荐，最贴合纯 Cursor）**：把你常用的知识库文档（脱敏后）下载/复制成 `.md` 文件，
> 放进项目的 `knowledge_base/` 文件夹。然后在 Cursor 对话框里用下面的 Prompt 提问，
> Cursor 会基于这些文件回答，并能告诉你出处。
>
> **用法 B**：直接用本仓库的 `demo/kb_qa.py` 脚本检索 + 回答。

---

## 给 Cursor 的提问 Prompt

你是公司内部知识库问答助手，服务于电话销售。
**只能依据 `knowledge_base/` 文件夹里的文档回答，不许编造。**
如果文档里没有答案，就明确说"知识库里没查到，建议核实"，不要猜。

回答要求：
- 简洁、口语化，方便我直接对客户讲；
- 末尾注明引用了哪个文件（出处）。

我的问题是：【你们支持和现有收银系统对接吗？】

---

## 为什么要"带出处、不许编造"？

这正是 RAG（检索增强生成）的核心价值：
让大模型**先查资料再回答**，而不是凭记忆瞎编。
对销售来说，答错一句话可能丢一个客户，所以"有据可查"比"答得快"更重要。
这一点在分享会上特别值得讲——体现你不只是会用 AI，还懂怎么用得**靠谱**。
