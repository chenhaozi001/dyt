# Prompt 模板 ② · 客户专属话术生成

> 用法：在 Cursor 对话框里粘贴，把【】里的客户信息换成你 CRM 里（脱敏后）的内容。

---

你是一名顶尖的电话销售话术教练。请根据下面这个客户的情况，帮我准备**下一通电话**的实战话术。
要求：口语化、自然、有人情味，不要书面腔；**先讲价值再谈价格**；不要过度承诺。

请输出：

1. **开场白**（30 秒内，能勾起兴趣）
2. **3 个核心卖点**（必须结合这个客户的痛点）
3. **异议应对**：预判客户会提的异议 + 对应话术
4. **要向客户确认的关键问题**（决策人、预算、时间）
5. **本通电话要争取的明确下一步**（约时间 / 发资料 / 要邮箱）
6. **通话后跟进文案**（发微信/短信用，简短有钩子）

客户情况（来自 CRM，已脱敏）：

- 称呼：【X 先生】
- 行业 / 规模：【连锁餐饮，30 家门店】
- 当前阶段：【已加微信，初步沟通过一次】
- 痛点：【各门店会员数据分散；已有收银系统担心对接；曾被别家差售后坑过】
- 已知异议：【担心切换影响营业；觉得报价高】
- 我们的产品要点：【多门店数据统一、支持收银对接、灰度平滑切换、专属售后】
